# sergeydertan.github.io

Privacy policies and support pages for my apps, served by GitHub Pages at
https://sergeydertan.github.io/.

## Layout
- `_config.yml`: site settings and the values every page uses (developer, the publisher on each store, contact email, privacy policy date)
- `index.md`: list of apps
- `multitool/privacy.md`, `multitool/support.md`: English pages
- `multitool/uk/`, `multitool/ru/`: the same pages in Ukrainian and Russian

The apps link to these URLs (Settings → Privacy policy, Help & FAQ), so don't move pages:
- `/multitool/privacy/`, `/multitool/uk/privacy/`, `/multitool/ru/privacy/`
- `/multitool/support/`, `/multitool/uk/support/`, `/multitool/ru/support/`

## Before publishing a change
- No value in `_config.yml` may still be a `[TODO: ...]`.
- A privacy policy change gets a new `privacy_effective` date, and all three languages change together.
